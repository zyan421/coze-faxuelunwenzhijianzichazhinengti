## 项目简介

本项目是一款面向**法学专业本科/研究生毕业论文**的 AI 质检自查工具。用户只需上传论文文件（Word / PDF），系统即可自动完成九维度深度审查，并输出：

1. **带批注的 Word 文档** —— 在原文对应位置插入修改建议批注
2. **PDF 审查报告** —— 结构化呈现所有问题及修改建议

系统基于 **LangGraph + FastAPI** 构建，支持 **SSE 流式输出**，提供完整的自定义 Web UI，并支持 **BYOK（Bring Your Own Key）** 模式灵活切换大模型。

## 功能特性

### 九维度智能审查
| 维度 | 审查内容 |
|------|----------|
| 选题 | 学术价值、创新点、研究意义 |
| 结构逻辑 | 章节比例、逻辑连贯性、层次清晰度 |
| 论证严谨性 | 论点论据匹配、论证深度、逻辑漏洞 |
| 文献综述 | 覆盖全面性、研究空白梳理、述评深度 |
| 实证分析 | 数据来源可靠性、研究方法适配性 |
| 规范适用 | 法条引用准确性、适用逻辑、时效性 |
| 语言表达 | 术语准确性、病句排查、学术规范性 |
| 对策建议 | 可操作性、可行性、针对性 |
| 学术不端 | 引用规范、重复风险、格式合规 |

### 格式校对
- **GB/T 7714** 顺序编码制引注格式自动校对
- 脚注、参考文献完整性检查
- 法条引用、案例名称、统计数据事实性标注「⚠️需人工核实」

### 交付物
- **批注版 DOCX**：在论文原文对应位置插入审查批注，可直接在 Word 中逐条修改
- **PDF 审查报告**：结构化排版，包含问题分类、严重程度、修改建议

### Web UI 功能
- 拖拽上传论文文件（支持 `.docx`、`.pdf`、`.txt`、`.md`）
- SSE 流式对话，实时显示审查进度
- 历史记录侧边栏，支持多轮对话
- **模型设置面板**：支持自定义 API Key、Base URL、模型名称
- 推荐预设：DeepSeek / 智谱 GLM / 通义千问 / 硅基流动

## 快速开始

### 方式一：Coze 平台一键部署（推荐）

1. 将本仓库导入 [Coze 扣子编码](https://www.coze.cn/)
2. 在「部署设置」中配置环境变量（详见下方「模型配置」）
3. 点击部署，获取 **Web SDK 链接** 和 **项目部署 URL**
4. 通过 `/ui/` 路径访问自定义界面

### 方式二：本地开发

```bash
# 1. 克隆仓库
git clone https://github.com/zyan421/coze-faxuelunwenzhijianzichazhinengti.git
cd coze-faxuelunwenzhijianzichazhinengti

# 2. 安装依赖（使用 uv）
uv sync

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env，填入你的模型 API Key

# 4. 启动服务
bash scripts/http_run.sh -m http -p 5000

# 5. 访问自定义 UI
open http://localhost:5000/ui/
```

### 方式三：运行 Agent 节点测试

```bash
# 运行完整工作流
bash scripts/local_run.sh -m flow

# 运行指定节点
bash scripts/local_run.sh -m node -n node_name
```

## 使用指南

### 1. 上传论文
在对话界面点击「上传文件」或直接拖拽 `.docx`/`.pdf` 文件到输入框，系统会自动读取论文全文。

### 2. 等待审查
Agent 会自动执行三步流程：
1. **读取论文** —— 解析文本内容
2. **深度审查** —— 九维度分析问题（SSE 流式输出审查结果）
3. **生成交付物** —— 生成批注版 DOCX + PDF 报告

### 3. 下载交付物
审查完成后，对话界面会显示两个下载链接：
- **批注版 Word 文档**：下载后在 Word 中查看批注，逐条修改
- **PDF 审查报告**：完整的结构化审查报告，适合打印或存档

> 下载链接 **24 小时内有效**，请及时下载保存。

### 4. 模型设置（可选）
点击右上角「模型设置」，可配置自己的大模型 API：
- **DeepSeek**：`deepseek-v4-pro` / `https://api.deepseek.com`
- **智谱 GLM**：`glm-4-plus` / `https://open.bigmodel.cn/api/paas/v4`
- **通义千问**：`qwen-plus` / `https://dashscope.aliyuncs.com/compatible-mode/v1`
- **硅基流动**：`Pro/deepseek-ai/DeepSeek-V3` / `https://api.siliconflow.cn/v1`

## 模型配置

### 环境变量

| 变量名 | 必填 | 说明 |
|--------|------|------|
| `CUSTOM_MODEL_API_KEY` | 是（BYOK 模式） | 你的大模型 API Key |
| `CUSTOM_MODEL_BASE_URL` | 是（BYOK 模式） | OpenAI 兼容接口地址 |
| `CUSTOM_MODEL_NAME` | 否 | 模型名称，如 `deepseek-v4-pro` |
| `COZE_WORKLOAD_IDENTITY_API_KEY` | 否（平台模式） | Coze 平台自动注入 |

> 详见 `.env.example` 完整模板。

### 推荐模型

| 推荐度 | 模型 | 平台 | 说明 |
|--------|------|------|------|
| ⭐⭐⭐ | DeepSeek-V3 / deepseek-v4-pro | DeepSeek | 法学理解能力强，性价比高 |
| ⭐⭐⭐ | GLM-4-Plus | 智谱 | 中文理解与长文本能力优秀 |
| ⭐⭐⭐ | Qwen-Plus | 阿里云 | 通义千问，指令遵循能力强 |
| ⭐⭐ | DeepSeek-V3 | 硅基流动 | 国内访问稳定，价格优惠 |

> ⚠️ **不推荐**使用轻量/迷你模型，可能导致批注位置不准或分析浅薄。

## 核心设计亮点

### 1. 三阶段精简工作流
将原先 6+2N 次 LLM 工具调用精简为 **3 次**：
1. `read_paper_file` —— 读取论文
2. LLM 直接分析 —— 一次回复完成九维度审查
3. `generate_deliverables` —— 同时生成批注 DOCX + PDF 报告

### 2. 容器隔离兼容
Coze 平台 Web 请求与 Agent 调用运行在不同容器，本地文件系统不共享。系统通过 **S3 对象存储 + 预签名 URL** 实现文件跨容器流转，确保文件读取与交付物生成可靠可用。

### 3. 错误处理与降级
- 工具执行错误通过 `@wrap_tool_call` 中间件捕获，返回友好错误信息，不阻塞 Agent 循环
- 文件读取失败时自动降级为基于用户提供的论文内容直接审查
- 超长文件名自动使用短 UUID 重命名，避免 S3 签名失败

### 4. 安全设计
- `.env` 已加入 `.gitignore`，API Key 不会泄露到仓库
- 支持多环境变量名兼容，方便不同部署方式迁移
