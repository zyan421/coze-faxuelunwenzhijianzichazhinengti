# "遗漏但应讨论"专项清单

> 这是张老师评阅书中最有价值的一类批评。识别论文"没写但该写"的题中应有之义，帮助作者补齐论证的完整性。

## 一、通用层（所有法学论文都应具备）

### G1 与核心概念相邻的兄弟概念

- [ ] 是否区分了核心概念与**最易混淆的近邻概念**？
  - 如研究"个人信息权益" → 是否区分了隐私权、姓名权、肖像权
  - 如研究"认罪认罚" → 是否区分了坦白、自首、立功
  - 如研究"行政处罚的明知" → 是否区分了刑法的明知
  - 如研究"归责原则" → 是否区分了归责规则、归责事由
  - 如研究"管辖权" → 是否区分了级别管辖、地域管辖、专门管辖
  - 如研究"立案登记" → 是否区分了立案审查制

### G2 上下位阶的规范

- [ ] 是否覆盖了宪法依据（若有）？
- [ ] 是否覆盖了相关的法律、行政法规、部门规章、司法解释、地方性法规、规范性文件？
- [ ] 是否覆盖了最新的指导性案例、典型案例？

### G3 审前—审中—审后 / 事前—事中—事后

- [ ] 程序法研究是否只谈了其中一阶段而忽略其他？
- [ ] 实体法研究是否只谈了权利规范而忽略了程序救济？
- [ ] 责任研究是否只谈了民事而忽略了行政、刑事的衔接？

### G4 国家 × 地方 × 行业三层规范的覆盖

- [ ] 地方立法（如省级条例、市级条例、自治区条例）是否纳入？
- [ ] 行业规范（如金融监管办法、证券交易所规则、律协规则）是否纳入？

### G5 反面论据与替代方案

- [ ] 对于本文的核心主张，是否讨论了**反对意见**？
- [ ] 是否讨论了**替代方案**？
- [ ] 是否说明了为什么选择本文方案而不选替代方案？

### G6 时间敏感的立法动态

- [ ] 论文定稿前 12 个月内，本主题有无重大立法？
- [ ] 论文定稿前 6 个月内，有无重要的司法解释或政策文件？

## 二、分主题预置清单（张老师评阅过的相关主题，可作为"应然讨论清单"参考）

以下清单按张老师评阅论文涉及的主题分类，列出**应讨论而常被遗漏**的关键点。使用时识别论文主题，调用对应条目进行检查。**具体的法律名称与时效以联网核实结果为准。**

### A. 个人信息保护 / 数据合规类

**应讨论清单**：
- [ ] 《个人信息保护法》《数据安全法》《网络安全法》的适用分层与协调
- [ ] 《民法典》第四编人格权编中关于个人信息的规定
- [ ] 与隐私权（《民法典》第 1032—1034 条）的区分
- [ ] 知情同意规则的适用边界
- [ ] 告知义务、删除权、决定权、查阅复制权、可携带权等具体权利
- [ ] 敏感信息 vs 一般个人信息的差别待遇
- [ ] 国家机关处理个人信息 vs 商业机构处理个人信息的区分
- [ ] 未成年人个人信息的特殊保护（《个人信息保护法》《未成年人保护法》《未成年人网络保护条例》）
- [ ] 公共利益下的个人信息限制（《民法典》第 999 条）
- [ ] 个人信息公益诉讼（《个人信息保护法》第 70 条）
- [ ] 最新政策文件（如《关于加快公共数据资源开发利用的意见》）

### B. 合同 / 债法类

**应讨论清单**：
- [ ] 新《民法典》合同编、物权编、侵权责任编之间的协调
- [ ] 旧《合同法》《担保法》《物权法》已废止（2021.1.1），不得作为主要依据
- [ ] 新《公司法》（2024.7.1 施行）对公司法相关内容的影响
- [ ] 《民法典》配套司法解释（合同编通则解释、合同编分则解释等）
- [ ] 最高法相关指导性案例
- [ ] 违约责任与侵权责任、缔约过失责任的区分
- [ ] 效力性强制性规定与管理性强制性规定的区分

### C. 刑事诉讼 / 监察类

**应讨论清单**：
- [ ] 2018 年《刑事诉讼法》修正 + 2021 年配套司法解释
- [ ] 《监察法》《监察法实施条例》《监察官法》
- [ ] 《法律援助法》（2022.1.1 施行）
- [ ] 认罪认罚从宽（《刑事诉讼法》第 15 条、第 174 条、第 201 条等）
- [ ] 值班律师制度
- [ ] 被害人 vs 犯罪嫌疑人 vs 被告人的权利保障差异
- [ ] 监检衔接程序、检警衔接、法检衔接
- [ ] 《人民检察院公益诉讼办案规则》
- [ ] 规范术语："公益诉讼起诉人"（2018 年后）

### D. 行政法类

**应讨论清单**：
- [ ] 新《行政处罚法》（2021.7.15 施行）
- [ ] 《行政复议法》（2024.1.1 施行）
- [ ] 《行政许可法》《行政强制法》
- [ ] 行政推定、行政明知、行政解释
- [ ] 行刑衔接（与刑事司法的对接）
- [ ] 新《国家赔偿法》
- [ ] 优化营商环境相关规定

### E. 民事诉讼 / 执行类

**应讨论清单**：
- [ ] 《民事强制执行法（草案）》动态（若论文讨论执行）
- [ ] 《民事诉讼法》修正（2023 年）
- [ ] 司法解释：民事证据规定、民诉法解释
- [ ] 执行和解、执行分配、参与分配
- [ ] 多元化纠纷解决机制（调解、仲裁、和解、诉讼的衔接）

### F. 农村 / 土地 / 集体经济类

**应讨论清单**：
- [ ] 《农村集体经济组织法》（2024.6.28 通过，2025.5.1 施行）
- [ ] 《村民委员会组织法》《妇女权益保障法》
- [ ] 《土地管理法》《土地管理法实施条例》
- [ ] 《农村土地承包法》《农村土地承包经营纠纷调解仲裁法》
- [ ] 《民法典》物权编中的集体所有权、承包地、宅基地
- [ ] 三权分置改革（所有权、承包权、经营权）
- [ ] 自然资源统一确权登记

### G. 人工智能 / 知识产权类

**应讨论清单**：
- [ ] 《著作权法》（2020 修正）
- [ ] 《生成式人工智能服务管理暂行办法》（2023.8.15）
- [ ] 《互联网信息服务深度合成管理规定》
- [ ] 国外典型案例：美国泰勒诉美国版权局案；德国汉堡地区法院 LAION 案
- [ ] 国内典型案例：菲林律所诉百度案（非"菲林公司"）、腾讯诉盈讯案、北京互联网法院 AI 生成图片案
- [ ] 合理使用、权利限制、邻接权
- [ ] 国际条约：《伯尔尼公约》《WCT》

### H. 证据法 / 鉴定类

**应讨论清单**：
- [ ] 《最高人民法院关于民事诉讼证据的若干规定》（法释〔2019〕19 号）
- [ ] 《最高人民法院关于适用〈刑事诉讼法〉的解释》（2021）
- [ ] 《人民检察院刑事诉讼规则》
- [ ] 电子数据、鉴定意见、证人证言的规则差异
- [ ] 非法证据排除规则
- [ ] 印证规则与自由心证

### I. 地方性研究（以 X 省 / X 市为例）

**应讨论清单**：
- [ ] 研究地域的省级地方性法规、政府规章、规范性文件
- [ ] 研究地域的典型案例、政策动态
- [ ] 研究地域的特殊省情/市情（经济、人口、产业结构等与选题的关联）
- [ ] 对策的**地域专属性**（能否换一个省就不成立）

### J. 中医医疗 / 医事法类

**应讨论清单**：
- [ ] 《中医药法》
- [ ] 《医师法》《执业医师法》历史关系
- [ ] 《医疗纠纷预防和处理条例》
- [ ] 《民法典》第七编侵权责任 第六章 医疗损害责任（第 1218—1228 条）
- [ ] 《医疗事故处理条例》
- [ ] 《中医药标准化行动计划》
- [ ] 中医 vs 西医的共性与个性（诊疗规范、注意义务、告知义务）

### K. 跨境 / 涉外类

**应讨论清单**：
- [ ] 《数据出境安全评估办法》《个人信息出境标准合同办法》《促进和规范数据跨境流动规定》
- [ ] 《全球数据跨境流动合作倡议》
- [ ] 美英《数据访问协议》（2022.10.3 生效）—— 全球首个数据跨境取证双边协议
- [ ] 《国际刑事司法协助法》
- [ ] 海牙系列公约

## 三、使用方法

1. **识别论文主题**：从标题、关键词、摘要中识别论文属于哪一或哪几类
2. **调用对应清单**：上述 A–K 清单按需调用（论文可能跨多个主题）
3. **逐项检查**：论文是否讨论了清单中的条目
4. **区分"无须讨论"与"应讨论而未讨论"**：如果作者主动说明了"本文不涉及 X"并给出理由，视为合规；如果完全未提及，则命中 Z-A-2
5. **输出在报告中**：把"遗漏但应讨论"的条目单独列入"应讨论而未讨论清单"段落

## 常用批评话术

- "属于……的题中应有之义，是该标题涵盖的基本研究任务。"
- "作为 202X 年完成的论文，作者竟忽略了这部里程碑意义的重要法律。"
- "这是全球首个 XX 双边协议，对该协议进行分析显然是本文题中应有之义。"
- "论文完全没有针对《XX 法》第 X 条规定的实施、救济、司法认定等进行分析和论证。"
- "至少应当解决的问题有……，但是在论文中，这些基本问题都未得到回答。"
- "既然论文标题是《XX》，就不该遗漏……等国外经典案件。"
