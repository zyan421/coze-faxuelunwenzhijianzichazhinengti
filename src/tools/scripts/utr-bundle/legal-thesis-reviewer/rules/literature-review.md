# 维度 ④ 文献综述与学理根基（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第五章（Z-L-1 至 Z-L-7）

## 检查清单

### L1 "研究综述"与"立法综述/制度介绍"的区分（最高频批评！）

- [ ] 文献综述章节的段落，主语是"X 学者主张…"还是"X 国规定…"？
- [ ] 若段落主语以"X 国《X 法》第 X 条……"为主，直接命中 Z-L-1
- [ ] "国外研究现状"部分是否实际上是"国外立法现状 / 国外制度运行现状"的拼接？
- [ ] "国内研究现状"部分是否夹杂了大量地方性立法的介绍（这些应放到后文对策或现状章）？

### L2 文献类型的多样性

- [ ] 梳理对象是否只有期刊论文？缺少专著？缺少学位论文？缺少报纸理论文章？
- [ ] 一篇硕士/博士论文的文献综述只有期刊论文时，直接命中 Z-L-2
- [ ] 研究方法部分声称要"利用图书馆、数据库、网络资源等途径"时，是否真的涉及了实体图书馆的纸质书籍？

### L3 外文文献原始出处

- [ ] 对国外学者观点的引用，是否转引自国内译文或国内学者的引介？
- [ ] 参考文献表中的外文文献，正文中是否实际援引、有所论述？
- [ ] 外文文献信息是否准确（作者姓名拼写、期刊名、卷期、页码）？

### L4 综述范围的合理性

- [ ] 选择哪些国家作为比较法对象，是否说明了理由？
- [ ] 为什么只选美国/德国而不选日本/韩国/港澳台？（张老师典型质询）
- [ ] 对所选国家的介绍是否简单、潦草，"忽而法条、忽而判例"？
- [ ] 是否遗漏了本学科**权威期刊的最新代表作**？（如《中国法学》《法学研究》《中外法学》最近 3 年相关论文）

### L5 综述与自身论点的一致性

- [ ] 是否存在"前文说已有学者研究了 X，后文却说现有文献缺乏对 X 的研究"的矛盾？
- [ ] 综述的结论是否支撑了本文的创新点定位？

### L6 综述的评论质量

- [ ] 是不是只在简单摘抄他人句段，缺乏自己的述评？
- [ ] 有没有对既有研究的**分类**（不同观点的分组）？
- [ ] 有没有对既有研究的**批评性反思**（而非罗列）？
- [ ] 有没有指出"既有研究的不足 → 本文要解决什么"的过渡？

### L7 综述的工作量

- [ ] 综述涉及的文献数量是否与论文档位匹配？（本科 ≥ 10、硕士 ≥ 20–30、博士 ≥ 60+）
- [ ] 涉及的外文文献数量是否与档位匹配？
- [ ] 综述是否包含**近 3 年**的新文献？

### L8 张老师典型点名的"应看但未看"文献（按选题主题给指示）

> 这是一个典型样本，并非硬性清单。审查时识别论文主题后，可联网检索"XX 主题 专著/权威期刊最新文献"再作判断。

- "公共数据开放/个人信息保护" → 《政府数据开放的法律问题研究》（中国社会科学出版社 2020）
- "刑事涉案财物处置" → 《刑事涉案财物处置的法律机制研究》(2018)、《刑事诉讼涉案财物处置程序研究》(2020)、《刑事涉案财物处置实体问题研究》(2024)
- "羁押必要性审查" → 陈卫东等《羁押必要性审查制度的理论与实践》（中国法制出版社 2019）
- "跨境电子取证" → 梁坤《数据主权与安全：跨境电子取证》（清华大学出版社 2023）
- "生成式 AI 著作权" → 《人工智能与著作权制度创新研究》、《论人工智能生成物的著作权保护》、《论人工智能生成内容的著作权法平等保护》（载《中国法学》2024 年第 1 期）
- "侵害个人信息权益精神损害赔偿" → 黄笑语《侵害个人信息权益精神损害赔偿研究综述》（《法学》2023 年第 6 期）；李东宇《论侵害个人信息权益的精神损害赔偿》（《财经法学》2023 年第 4 期）；龙松熊《论侵害个人信息权益的损害赔偿》（《中国海商法研究》2023 年第 4 期）
- "合同编绿色条款" → 《论〈民法典〉绿色原则的合同适用及其制度启示》（CSSCI 2023）、《绿色原则规范解释实案释法》（中国人民大学出版社 2022）

## 常用批评话术

- "'国外制度现状'并不等于国外'研究'现状。"
- "对各国立法、司法实践的介绍，属于域外比较内容，而非研究综述。"
- "应当综述的是外国专家学者的学术研究成果，而非国内学者引介考察其他国家情况的成果。"
- "文献综述范围不全面、不准确，可能直接导致作者自以为的'创新'不符合学术界的实际情况。"
- "梳理和评价的对象全部都是期刊，没有一部著作，反映出作者对文献的认知还不够到位，检索文献不够全面。"
- "作者只对个别文献进行了简单的观点摘抄，未围绕自己选题的研究重点和难点展开有效的综合性评述。"
- "对各个国家所介绍的内容，简单、潦草，忽而列举法条，忽而列举个案判决，莫名其妙，缺乏条理性、逻辑性。"
- "对本学科及相关领域的研究动态和最新成果归纳总结不够。"

## 写作实操建议

- **三分式结构**：国内既有研究 + 国外既有研究 + 对既有研究的反思和本文的切入点
- **分类述评**：把所综述的文献按观点分 2–4 个流派，每一流派指出 1–2 个代表学者和代表作
- **引用外文文献时同时标注原文出处**：从译文看到的观点，至少核对一次英文原文
- **综述检查回归**：写完综述后，自问"读者能从我的综述里看到既有研究的主要分歧点吗？"
