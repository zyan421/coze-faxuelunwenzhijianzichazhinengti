# 维度 ⑤ 实证 / 数据 / 案例使用（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第六章（Z-E-1 至 Z-E-7）

## 检查清单

### E1 声称的研究方法是否落地

- [ ] "研究方法"章提到了哪些方法（案例分析法、调查问卷法、访谈法、实证研究法、比较研究法等）？
- [ ] 每一种方法在正文中是否有对应的章节产出？
- [ ] 如果声称采用了"调查问卷"，正文是否呈现问卷设计、样本量、回收率、数据处理过程？
- [ ] 如果声称采用了"访谈法"，正文是否有访谈对象、访谈时间、访谈内容的呈现？
- [ ] 如果声称采用了"案例分析法"，全文是否有真实的案例剖析？（而非仅提到案号）
- [ ] 如果声称采用了"比较研究法"，是否真的做了中外比较分析，还是仅介绍了外国制度？

### E2 案例选取

- [ ] 案例来源是否全面（司法裁判 + 执法案例 + 新闻报道案例，而不只是司法裁判）？
- [ ] 案例数量是否足以支撑结论？（仅 1–2 个案例得出一般性结论时命中 Z-E-2）
- [ ] 案例是否具有代表性？（作者是否说明为何选这些而不选那些）
- [ ] 同一案例是否反复出现在不同章节，凑数式使用？

### E3 裁判文书检索方案

- [ ] 作者是否交代了检索平台（中国裁判文书网、北大法宝、威科先行、无讼等）？
- [ ] 检索词、检索语法、筛选条件是否透明？
- [ ] 样本数量是否合理？（检索到数百万条但未筛选直接使用是警报信号）
- [ ] 检索时间段、地域、法院层级的限制是否说明？
- [ ] 是否剔除了重复案例、无关案例？

### E4 数据的元信息

- [ ] 每一项重要数据都有来源注释吗？
- [ ] 数据是第一手（官方统计）还是多手转引？
- [ ] 数据发布年份是否过于陈旧？（> 5 年前的数据要警惕）
- [ ] 百分比之和是否为 100%（汇总错误是张老师发现过的典型低级错误）？
- [ ] 样本量与推论范围是否匹配？（小样本、局部样本不宜推全国性结论）

### E5 图表规范

- [ ] 图表是否有标题？
- [ ] 图表是否有图注 / 表注说明来源、单位、样本量？
- [ ] 图例是否清晰、区分度足够？（颜色相近导致读者无法辨别是张老师点过的典型问题）
- [ ] 图表是否在正文中被提及、被分析？

### E6 案例与理论 / 数据与论点 的衔接

- [ ] 案例章是否"只讲案情不讲法理"？
- [ ] 数据统计后是否有分析文字，还是"摆出来就完事"？
- [ ] 案例/数据所支撑的结论，是否与前后章节呼应？（否则命中 Z-S-6 "两张皮"）
- [ ] 所得的统计数字是否真的支撑作者的论点？（例如"50% 参与率"的计算是否站得住脚）

### E7 核查案例与裁判文书的真实性（学术不端红线）

- [ ] 论文标注的案号是否对应真实存在的裁判文书？（需联网核实）
- [ ] 论文复述的裁判主文、判决要旨是否与裁判文书原文一致？
- [ ] 论文中的当事人姓名、公司名称是否与裁判文书中的一致？
- [ ] 论文中的"最高法典型案例""指导性案例"是否真实存在？（需联网核实）

> ⚠️ **E7 是最关键的学术不端检查项**。张老师多次通过"实际检索"发现论文中的案号对应的实际是另一类案件，或判决主文被篡改。这类问题必须联网核实。

### E8 实证方法的选择是否合理

- [ ] 实证研究的样本来源是否契合研究对象？（如研究"被害人在认罪认罚从宽程序中的参与"，样本应是检察机关的《认罪认罚具结书》等而非裁判文书网的判决）
- [ ] 实证研究的颗粒度是否与论点匹配？
- [ ] 是否混用了不能相除的两个数据得出百分比？（张老师发现过的典型错误）
- [ ] **样本来源的"恰当性"要论证**——即使是权威数据库（如中国裁判文书网），也未必是反映特定研究对象的"恰当来源"。例如研究"被害人在认罪认罚程序中的参与情况"，裁判文书网的判决书"对被害人的庭审参与的确有一定记载，但未必是反映被害人参与认罪认罚从宽程序情况的恰当来源"——真正的数据源应该是检察机关的《认罪认罚从宽制度告知书》《认罪认罚具结书》《量刑建议调整书》等程序性文书（r19 的典型批评）

### E9 比较研究法的合理使用

- [ ] 比较法研究是否流于表面（只介绍外国制度，不做中外对比）？
- [ ] 比较对象的选择是否有理由（为什么选美国、德国而不选日本、韩国）？
- [ ] 比较研究的结论是否真正启发了国内对策？还是"启示与对策两张皮"？

## 常用批评话术

- "声称本研究采用了'XXX 方法'……但全文根本未采用该方法。"
- "案例分析方法运用不到位，对案例的运用和分析深度是很不够的，缺乏深入的法理剖析，难以有力支撑论点。"
- "检索方案较为粗疏，统计数据对论证的支撑作用不大。"
- "未对数据的来源、构成、样本数量、统计口径做交代，研究方法的科学性和数据可靠性论证不足。"
- "这怎么能和……的占比混为一谈呢？这表明作者对研究对象认识不清。"
- "案例的分析过于粗浅，未能结合前述理论章节进行剖析。"
- "图示和表格均缺乏数据单位、标签等必要的元素。"
- "经核对，案号……的裁判主文中已经写明……，并非作者所说的……。"

## 写作实操建议

- **研究方法与章节映射表**：写作前先做出一张"我声称的方法 → 正文第 X 章节落地"的映射表，确保无"方法挂羊头卖狗肉"
- **数据三问**：每引用一个数据问自己——来源是什么？发布时间是什么？样本范围是什么？
- **案例使用模板**：基本案情（200 字内）+ 争议焦点 + 法院裁判要旨 + 与本文论点的关联（本案如何支撑/反驳本文 A 主张）
- **图表自检**：读者看到图表的那一瞬间，不看正文，能判断"作者要表达的是什么"吗？
