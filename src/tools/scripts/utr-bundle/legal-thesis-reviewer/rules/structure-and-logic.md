# 维度 ② 结构与逻辑（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第三章（Z-S-1 至 Z-S-7）

## 检查清单

### S1 入题速度

- [ ] 第二章是否为"XX 概述"？占正文比重是否 > 15%？
- [ ] 概述章是否只是"编教材式、普法式"的一般性介绍，没有自己的分析？
- [ ] 概述章中定义—特征—意义—功能的模板套用是否直接搬自他人论文？
- [ ] 如果删除概述章，文章是否仍能成立？（若能，则建议删除）

### S2 章节/内容重复检测

- [ ] 两个以上小标题表述高度相近？（如"4.2 违约责任归责原则的法律效力问题"与"4.3 违约责任归责原则的法律适用问题"）
- [ ] "原因分析"章与"存在问题"章的论据是否大段重合？
- [ ] 对策章的各小节之间是否存在交叉（如"提高透明度"与"强化监管"内容相似）？
- [ ] 在同一章内，同一段落是否复现？（疑似"凑字数"）

### S3 文不对题（在章节粒度上逐节检查）

- [ ] 每个小节的第一段、最后一段的主题词，与该小节的标题主题词是否一致？
- [ ] 如果小节标题是"X 的定义"，内容是否实际讨论了定义，还是在讨论相邻概念？
- [ ] "施行"与"履行"、"权利"与"权力"、"执行"与"履行"等容易混用的词，小节标题与内容是否一致？
- [ ] "现状分析"这种章节是否被当成了"任意内容的筐"？

### S4 段落划分

- [ ] 是否存在单段跨 2+ 页的情况？
- [ ] 是否存在一节只有 1–2 段的情况？
- [ ] 是否有"一节一段"的小节 ≥ 3 处？
- [ ] 单段是否有清晰的主题句、论据、论证、结语四要素？

### S5 章节衔接

- [ ] 每章开头是否有对上一章的呼应？
- [ ] 每章结尾是否为下一章做铺垫？
- [ ] 章与章之间是否仅靠标题衔接，没有过渡段落？
- [ ] 域外考察章与国内对策章是否做了有机融合？（若启示独立一章、对策独立一章，两章论据不对话，则命中 Z-S-6 "两张皮"）

### S6 逻辑周延性与自相矛盾

- [ ] 同一概念在不同章节的界定是否一致？
- [ ] 作者的主张 A 与在其他章节得出的结论 ¬A 是否共存？
- [ ] "既然断言 X，却又……"是张老师发现矛盾的典型句式，审查时可逐节回扫。

### S7 摘要—目录—引言—结语的内部一致性

- [ ] 摘要概括的研究内容是否与目录的章节分布对应？
- [ ] 引言提出的问题是否在结语中得到回应？
- [ ] 结语中提到的"未尽研究"是否其实就是标题覆盖的题中应有之义？（命中 Z-P-5）
- [ ] 英文摘要是否与中文摘要在信息密度、术语、结构上对应？

## 常用批评话术

- "入题太慢，'X 概述'这一章可以省略。"
- "两部分内容完全重复，存在凑字数嫌疑。"
- "章节之间互相抄袭、复制，学术态度极不端正。"
- "基本未提及（该小节标题所称的主题），文不对题。"
- "这一小节竟然只有 1 段，而这 1 个自然段竟然纵跨 X 页，使得文章的层次性和可读性欠缺。"
- "在章与节之间、节与节之间，缺乏衔接、过渡段落，行文显得突兀、不连贯。"
- "一般理论与现状评价和原因分析之间呈现出'两张皮'。"
- "前后矛盾。"

## 写作实操建议（供给用户修改参考）

- **合并冗余章节**：按"问题—原因—对策"三章制取代"概述—现状—问题—原因—对策"五章制
- **章节衔接句模板**：每章末尾写一句"上述分析揭示了 X。下一章将在此基础上，进一步讨论 Y"
- **标题与内容回扫法**：写完一章后，先不看标题，用一句话概括本章讲了什么，再回看标题是否一致
- **同类项合并**：对策章的小节之间交叉时，先列出每个小节真正独立的着力点，再合并
