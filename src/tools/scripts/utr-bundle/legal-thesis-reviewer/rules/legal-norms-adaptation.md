# 维度 ⑥ 法律文本与规范适用（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第七章（Z-N-1 至 Z-N-8）

## 检查清单

### N1 法律名称规范性

- [ ] 首次出现的法律名称是否使用完整、规范的全称（含必要的立法机关或法释号）？
- [ ] 首次使用简称前是否约定（"（以下简称'XX'）"）？
- [ ] 同一法律在全文中的简称是否一致？
- [ ] 自造简称是否可能引起歧义？（如"《民事证据新规》"应改为《最高人民法院关于民事诉讼证据的若干规定》（法释〔2019〕19 号））

### N2 新旧法替换（最容易出问题）

- [ ] 正文引用的法律是否仍是废止的旧法？
- [ ] 新旧法更替前后的关键规则变化是否被作者掌握？
- [ ] 作者是"未关注新法"还是"未加审查地借鉴了旧研究成果"？
- [ ] 已被新规范替代的司法解释是否还在被援引？

### N3 不存在的法律名称（常识性错误，易触发 Z-N-2）

- [ ] 是否出现了"《民法典通则》"这样**并不存在**的法律？
- [ ] 是否出现了"《经济法》""《环境法》"这种法律**作为单部法典并不存在**？（正确为《经济法学》教材、《环境保护法》）
- [ ] 是否出现了"中国裁判网"（正确为"中国裁判文书网"）、"法言灯塔"（不存在的检索平台）？

### N4 条文号与条文内容对应

- [ ] 论文援引的条文号对应的内容，与现行法是否一致？
- [ ] 是否有"某法第 X 条规定了 Y"但实际第 X 条规定的是另一事项的情况？
- [ ] **需联网核实**：如《反电信网络诈骗法》第 25 条是否涉及"应当知道"（实际不涉及，张老师在评阅中指出）
- [ ] 法条的旧条文号在修法后是否已变动？

### N5 立法动态敏感性（时间戳检查）

- [ ] 论文完稿日期（封面标注）后的 **12 个月内**，是否出台了与本文主题**直接相关**的重要立法？若有而论文未提及，命中 Z-N-5。
- [ ] 论文是否关注了本领域的部门规章、行政法规征求意见稿？
- [ ] 地方性立法（省条例、市条例、政府规章）是否被纳入？
- [ ] 指导性案例、典型案例是否被纳入？
- [ ] 国家政策文件（中共中央办公厅、国务院办公厅联合印发的意见等）是否被纳入？

### N6 规范术语的准确性

- [ ] "公益诉讼人"还是"公益诉讼起诉人"？（2018 年后应为后者）
- [ ] "大陆 vs 台湾"、"内地 vs 港澳"—— 是否混用？
- [ ] "审判阶段"、"审查起诉阶段"、"侦查阶段"、"执行阶段"—— 是否正确使用？
- [ ] "归责原则 vs 归责规则"、"责任 vs 义务 vs 制裁"—— 是否区分？
- [ ] "适用 vs 使用 vs 应用"—— 是否滥用"适用"？

### N7 发文机关的准确性

- [ ] 规范性文件的发文机关是否完整列出？（如《关于依法惩治妨害国（边）境管理违法犯罪的意见》应列出最高法、最高检、公安部、国家移民管理局四家）
- [ ] "两高"文件是否被错标为单独一家？
- [ ] 部委联合印发的文件是否遗漏了某家？

### N8 规范层级

- [ ] 作者是否混淆了法律、行政法规、部门规章、地方性法规、地方政府规章、规范性文件？
- [ ] 作者援引司法解释时是否注意其与法律的效力位阶关系？
- [ ] 主张"上升为法律"或"专门立法"时，是否论证了"为什么现有较低层级规范不够用"？

### N9 数据/事实的时效性

- [ ] 论文中的统计数字是否是近 2–3 年的？
- [ ] 论文中描述的行政机关职能、管辖范围、工作方式是否反映现状？
- [ ] 描述的社会现象、技术发展阶段是否仍然成立？（如 2020 年前的 AI 能力描述在 2024 年已严重滞后）

## 常用批评话术

- "援引法条建议以新法为准，避免以讹传讹。"
- "作为 202X 年完成的论文，作者竟忽略了这部里程碑意义的重要法律，属于重大疏失。"
- "《X 法》第 Y 条完全不涉及……。"
- "这种不一致的表述也欠严谨。"
- "作者似乎并不知道有这个协议/法律/条例的存在。"
- "不修改将导致以讹传讹。"
- "作者写作期间未能将新出台的直接相关的《XX 法》结合起来，导致研究成果的实际贡献度不足。"
- "我国并不存在《XX 法》。"
- "首次提到法律名称时，应当表达规范、准确的全称。"

## 写作实操建议

- **立法时间戳回扫**：在论文封面定稿日前 12 个月内，用核心关键词在"国家法律法规数据库"、"国务院法制信息网"、"最高法/最高检网站"做一次全面回扫
- **"三表检查"**：法律名称表、条文号表、发文机关表——逐条核对
- **规范名称词典**：在写作前建立本文出现的所有规范性文件的"全称—简称—发布机关—发布时间—效力"对照表，贯穿全文一致使用
