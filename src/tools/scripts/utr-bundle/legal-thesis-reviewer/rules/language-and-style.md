# 维度 ⑦ 语言表达与学术规范（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第八章（Z-W-1 至 Z-W-7）

## 检查清单

### W1 基础语病检查

- [ ] 是否存在语义重复？（如"主要存在以下主要问题""其主要主题分布主要集中在"）
- [ ] 是否缺少主语或主语不明？
- [ ] 是否存在成分残缺、搭配不当？
- [ ] 是否存在语义矛盾的句子？
- [ ] 是否有"没头没脑"的句子（脱离上下文读不懂）？

### W2 标点、错别字

- [ ] 是否大量误用全半角标点？
- [ ] 书名号是否打全？
- [ ] 双引号与单引号是否嵌套正确？
- [ ] 是否存在"句号单独成段"这类格式错误？
- [ ] 是否有错别字？（张老师点过"表面→表明""答多数→大多数""截止→截至""其它→其他""于→与"等）
- [ ] 双数页是否有页码？
- [ ] 目录中是否有"错误！未定义书签"、"MASTER DISSERTATION"这类格式错误？
- [ ] 每一章节的小标题后是否有多余标点？

### W3 摘要与英文摘要

- [ ] 中文摘要是否只是目录的简单重复？
- [ ] 中文摘要是否包含：研究背景、问题、方法、主要观点/贡献、结论？
- [ ] 英文摘要是否有机翻痕迹？（典型：专有名词翻译错误、语序生硬、主谓不一致）
- [ ] 英文标题、关键词的翻译是否规范？
- [ ] 专有名词（如国外期刊名、数据库名、外国立法）的英文是否采用官方名称？

### W4 匿名化

- [ ] 论文引用的裁判文书当事人是否已匿名化（按"陶某""赵某伟"等方式）？
- [ ] 匿名化是否彻底——同一段中是否同时出现了匿名和真名？
- [ ] 涉及公众人物（官员、知名学者）的称呼是否规范？

### W5 术语使用的准确性

- [ ] "适用"一词是否被滥用（一段话中出现 3 次以上即警报）？
- [ ] "法治"与"法制"是否区分？
- [ ] "法系"的描述是否准确？
- [ ] 专有名词的译名是否在全文统一？（如同一外国法律在不同章节是否翻译一致）
- [ ] **动宾搭配是否得当**？——张老师指出过"推定治理"的错误（一项"原则"能否"治理"）、"建立多元纠纷解决机制"（已有的机制不能"建立"只能"完善"）等典型搭配错误
- [ ] "车轱辘话"检测：是否存在大段"XXX 在很大程度上符合……当然，某些具体权利和处罚力度可能需要根据实际情况进行调整"这类空洞的、无实际意义甚至文不对题的表述？

### W6 文体与篇幅

- [ ] 学术论文的文体是否混入了口号式、工作报告式、散文式表达？
- [ ] 是否存在大段堆砌、冗余、凑字数？
- [ ] 句子平均长度是否过长（> 80 字单句需考虑拆分）？
- [ ] "硕士论文……篇幅过长、重复内容太多，建议删繁就简、理顺思路、精炼表达。"—— 是否有此风险？

### W7 图表与公式规范

- [ ] 每一张图是否有标题、编号、数据来源、单位？
- [ ] 每一张表是否有表号、表题？
- [ ] 公式是否编号、居中？
- [ ] 图表是否被正文引用（如"如图 2-1 所示"）？

### W8 引注与参考文献形式（简版，详细由 `legal-citation-checker` 负责）

- [ ] 引注体例是否全文一致（国标 7714 / 《法学引注手册》 只能选一）？
- [ ] 首次出现的完整注释 vs 之后的短注是否规范？
- [ ] 每个引注是否信息完整（作者、篇名、期刊名、卷期、年份、页码）？
- [ ] 正文中提及的文献是否都在参考文献表中？参考文献表中的文献是否都在正文中被援引？

### W9 学术研究伦理性表述

- [ ] 自我表述（"本文""笔者"）是否规范？
- [ ] 是否出现了"我认为""我相信"这类不符合学术论文文体的表述？
- [ ] 是否有"显然""毋庸置疑""众所周知"等需要论证却未论证的断言？
- [ ] 关键性主张前是否有充分的限定语（如"在 XX 情境下""就 XX 问题而言"）？

### W10 对应的学位论文格式规范

- [ ] 是否符合所在院校的《研究生学位论文撰写规范》？
- [ ] 目录、摘要的位置顺序是否正确（张老师点过"似乎放反了"）？
- [ ] 封面、封二、致谢、声明页是否完整？

## 常用批评话术

- "论文语言表达存在较多语法错误，例如……以及标点误用情况。"
- "作为学术论文，属于科学研究的成果，应当抱着高度负责的态度，因而建议作者接下来逐字符通读全文，修正不通顺、不准确的表述。"
- "英文摘要明显是机翻的。"
- "俯拾皆是的语法错误，反映出作者的语言文字功底有待提升。"
- "作者对'适用'一词的理解有偏差，总是滥用'适用'或'适用性'一词。"
- "匿名化处理不彻底。"
- "写完后未通读校对，存在低级错误。"
- "学术论文不是越长越好。"

## 写作实操建议

- **逐字符通读法**：打印纸质版后用笔逐字符通读一遍，找到 90% 以上的低级错误
- **TTS 辅助**：用朗读软件把全文读一遍，听不顺畅的地方即是需要修改的地方
- **英文摘要母语者审阅**：不要直接机翻
- **关键词词频检查**：对"适用""使用""应用""完善""加强"等高频虚词做词频统计，若某一段出现 > 3 次，考虑换词
- **图表独立可读性**：遮住正文，仅看图表能否读懂
