# 维度 ③ 论证深度与核心观点（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第四章（Z-A-1 至 Z-A-5）

## 检查清单

### A1 论证是"深入剖析"还是"堆砌材料"

- [ ] 案例 / 裁判文书的使用是否停留在"基本案情 + 裁判结果"的复述，没有法理剖析？
- [ ] 案例引用是否孤立存在，没有和本文提出的论点挂钩？
- [ ] 多个学说是否只是并列介绍，没有作者自己的评价和选择？
- [ ] 整章整节是否在"文献回顾"的层面滞留，没有作者自己的主张？

### A2 "应讨论而未讨论"项清单

按选题主题扫描以下问题是否得到讨论：

- [ ] 与核心概念存在**邻近但不同的兄弟概念**（如行政推定 vs 刑事推定、个人信息 vs 隐私、权利 vs 权力），是否区分讨论？
- [ ] 与研究对象直接相关的**最近 2 年新立法 / 司法解释 / 指导性案例**是否涉及？
- [ ] 选题中暗含的**原则性问题**是否被讨论？（如"律师帮助权"是否宪法性权利的必要性论证）
- [ ] **反面论据 / 替代方案**是否被讨论？
- [ ] **审前 / 审中 / 审后阶段**的衔接是否讨论？（只谈审判却忽略侦查/执行）
- [ ] **学说间的相互关系和逻辑脉络**是否讨论？（而不仅是并列介绍）
- [ ] 已有的**指导性案例 / 典型案例**是否被纳入？

### A3 观点是否有论据支撑

- [ ] 每一段的"断言句"后是否有注释 / 案例 / 数据 / 法条作为支撑？
- [ ] 出现"显然""毋庸置疑""众所周知""大量实践表明"时，后续命题是否真的无需论证？如否，则命中 Z-A-3。
- [ ] 观点中的量化描述（"XX 率高达 68%""增长 42%"）是否有出处？
- [ ] 关键论据的量级是否合理？（如统计数据是否与公开统计口径一致）

### A4 核心概念的界定

- [ ] 文章自创的概念（如"推定率""双阶反驳机制""临界值"）是否明确定义了？
- [ ] 定义中是否存在自相抵触？（如内涵界定覆盖范围 ⊊ 外延列举范围）
- [ ] 是否混淆了主规则库"常见错误对"列表中的概念（权利/权力、法治/法制、内地/大陆 等）？
- [ ] 专业术语的使用是否在全文保持同一含义？

### A5 理论运用是否适配本题

- [ ] 所借用的其他领域理论（如"社会综合治理"用于"关键信息基础设施保护"）是否适配？
- [ ] 所采用的学说是否是最新、最权威的，还是已经被学界反思甚至淘汰的？
- [ ] 外国法律原理是否脱离了其原本的语境（如比较法研究中"生搬硬套"）？

### A6 论证的层次性

- [ ] 正当性论证—必要性论证—可行性论证—具体设计，四层是否具备？
- [ ] 制度建议是否论证了"为什么要改"+"为什么这样改"+"改了有什么风险"？

### A7 宪法性 / 原则性命题的论证

- [ ] 如果文中出现"应当作为宪法性权利确认""应当上升为法律""应当专门立法"等主张，是否做了充分论证？
- [ ] 该主张是否回答了"为什么不能停留在现有层级"的问题？

## 常用批评话术

- "案例分析方法运用不到位，特别是第 X 章，对案例的运用和分析深度是很不够的，缺乏深入的法理剖析，难以有力支撑论点。"
- "大多停留在只言片语的现象描述，而未能结合前序章节提出的一般理论，深入挖掘案例背后的法律适用逻辑和争议焦点。"
- "对核心概念的辨析和论证有待加强。"
- "恰恰是……的题中应有之义，是该标题涵盖的基本研究任务。"
- "部分观点缺乏论据支撑。"
- "拍脑袋。"
- "作者的论证很多都是类似不具有说服力的表述，尽管字数写得很多。"
- "从关联非常微弱的研究领域借壳套用在本题目中，属于生搬硬套，缺乏适配性。"
- "作者对软法、硬法的内涵和外延认识错误，对调解的分类和功能认识错误，对……的关系认识错误。"

## 写作实操建议

- **论据金字塔**：每一个主张 → 学说 + 法条 + 案例 + 数据四选二作为支撑
- **邻近概念区分表**：写作前列出与本论文核心概念接近的 3–5 个概念，逐一区分
- **正反论证法**：每提出一个主张，先列出反对意见，再论证为什么自己的主张更优
- **深水区标尺**：你的章节写出来后问自己——"如果一个已经读过本主题 5 篇期刊论文的研究生来看，他会觉得有新收获吗？"
