# 维度 ⑨ 学术不端线索识别（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第十章（Z-I-1 至 Z-I-9）
>
> ⚠️ **重要原则**：本 skill 只识别"线索"，不做最终定性。对任何可疑问题，使用"涉嫌""疑似""存在 X 线索""建议校方进一步核查"等表述，**不直接宣告"剽窃""造假"**。定性权归学术规范主管机构。

## 一、无需联网即可发现的线索

### 1.1 伪注 / 伪造文献的内部自证线索

- [ ] 正文引用了某某学者的观点，但参考文献表中没有该学者的文献？
- [ ] 参考文献表中的某文献在正文中从未被援引？
- [ ] 外文文献的作者姓名、期刊名拼写不符合英文学术习惯？（如全半角乱用、大小写错乱）
- [ ] 同一作者在不同章节被标注为不同国籍？
- [ ] 引用的"教授""院士"身份与作者已知背景不符？
- [ ] 参考文献表中的外文文献主题与本文主题明显无关（如法学论文中出现充电桩、社交网络、毒品犯罪等无关文献）？

> 张老师典型发现："参考文献中列举的韩德培、陈卫东、王利明、江平、张明楷、黄某有等文献，均系杜撰。其中，黄某有仍然在服刑。"

### 1.2 参考文献"注水"线索（典型"复制粘贴来的文献"）

- [ ] 英文参考文献主题与论文主题毫无关系（如监察法论文出现关于毒品犯罪的社交网络分析文献、HBO 电视剧《火线》的研究）
- [ ] 某类文献突然密集出现在参考文献表某一段（5 条以上连续无关文献）
- [ ] 外文文献的篇名、期刊名出现罕见拼写错误组合

### 1.3 大面积改写式抄袭的内部线索

- [ ] 某章/某节的专业术语密度、学术风格、论证节奏与本文其他部分显著不同？
- [ ] 某章/某节的章节编号风格与本文其他部分不同？（如本文是"（一）"小节制，某章突然是"1.1"小节制）
- [ ] 某章/某节引用的文献风格（格式、编号、标点）与其他章节不同？
- [ ] 同一作者的同一论文不同版本的章节编号不一致？
- [ ] 某章内突然讨论了与本题无关的主题（如"离婚经济补偿"论文第五章第一段写的是"证券虚假陈述案件中的民事责任"）？

### 1.4 数据造假的内部线索

- [ ] 关键数据无出处？
- [ ] 关键数据的样本量、总量、比例逻辑不自洽（如加总不为 100%）？
- [ ] 所引用的"典型案例""指导性案例""行业数据"来自不知名或可疑的来源（如"法言灯塔"这种不存在的平台）？
- [ ] 统计计算方法粗疏，分母分子不对应（如用全案被害人数除以认罪认罚案件数得出"50% 参与率"）？

### 1.5 研究方法造假的内部线索

- [ ] 研究方法声称了"案例分析法""调查访谈法""问卷调查"，但正文完全没有对应的章节？
- [ ] 附录附了空白问卷，但正文没有数据呈现？
- [ ] 声称"访谈了 X 位法官"，但无访谈对象、时间、内容的任何记录？

### 1.6 文风突变的内部线索

- [ ] 某一段的语气从"学术"突变为"新闻报道"或"工作报告"？
- [ ] 某一段的语法风格从中式转为翻译腔或欧化句式？
- [ ] 段内论证密度、引注频次骤然提升或下降？

### 1.7 裁判文书篡改的内部线索（部分可内部识别，部分需联网）

- [ ] 论文引用的同一案件的案号、法院、当事人前后不一致？
- [ ] 正文某案号对应的注释标注的是另一个案件的案号？
- [ ] 对当事人姓名、公司名称的拼写存在细微但系统性的偏差（故意微改以避开检索）？

## 二、需要联网核实的线索（必检项，若有联网工具）

详见 `online-verification.md`，此处仅列出联网必核的**五类对象**：

1. **法律名称 / 条文号 / 条文内容**
2. **司法解释 / 规范性文件（发布机关、发文字号、时效性）**
3. **裁判文书案号（审理法院、当事人、裁判时间、主文）**
4. **指导性案例 / 典型案例的真实性**
5. **学术文献的存在性（作者、篇名、期刊、卷期、页码的组合）**
6. **关键统计数据 / 政府公开数据**

## 三、处理流程

### 3.1 发现单一可疑线索时

- 在审查报告"九大维度"的相应维度中标记（如 Z-I-2 伪注）
- 不单独开设"学术不端"段落

### 3.2 发现 ≥ 2 处可疑线索时

- 在审查报告开头的"⛔ 致命问题"段落单独列出，使用以下表述：

  > ⚠️ **学术诚信风险提示**
  >
  > 本次审查发现以下**与学术规范冲突的线索**，其严重程度已超出一般格式问题范畴。**审查者不直接定性为学术不端**，但建议作者逐一核实、修改，并在必要时由所在院校学术规范主管机构做进一步核查：
  >
  > 1. [具体线索 1]
  > 2. [具体线索 2]
  > ...
  >
  > 参考依据：《高等学校预防与处理学术不端行为办法》（教育部令第 40 号）第 X 条。

### 3.3 发现大面积改写式抄袭的强线索时

- 仍不直接定性
- 建议作者："请作者提供写作过程中的主要参考来源和引用记录，以供进一步核对。"
- 在报告中说明："第 X 章与 Y 学位论文（需核实）存在高度相似的章节结构和论证脉络，建议作者主动说明借鉴来源并完整标注。"

## 四、与学校学术规范主管机构的衔接

- 本 skill 产出的审查报告**可以作为**导师、答辩委员会、学术诚信委员会进一步调查的参考材料
- 报告中可附上"**建议进一步调查的线索清单**"，但**不代替**学校正式的查重报告、盲审定性
- 查重报告（如知网查重）与本 skill 的审查是**互补**关系：查重发现的是**文字相似度**，本 skill 发现的是**改写式抄袭、伪注、方法造假**等查重软件不容易发现的问题

## 常用批评话术

- "涉嫌伪造文献。"
- "存在伪注行为。"
- "存在严重的抄袭、拼凑他人研究成果的情况。"
- "大面积'改写式'抄袭。"
- "这样大面积雷同的情况，已经构成学术剽窃，严重违背诚实信用。"（需有硬证据才用此表述）
- "《高等学校预防与处理学术不端行为办法》规定：'伪造科研数据、资料、文献、注释，或者捏造事实、编造虚假研究成果'属于学术不端行为。"
- "作者应当系统梳理全部论据、参考文献和注释的准确性，做重大修改。"
- "这篇论文如果不是复制自他人研究成果，那么就意味着论文中存在不实表述。"
- "论文一旦就此发布还将误导读者，以讹传讹，对导师、学院、学校乃至参阅者造成严重负面影响。"
