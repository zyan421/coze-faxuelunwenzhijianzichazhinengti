# 维度 ⑧ 对策建议与结论（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第九章（Z-P-1 至 Z-P-6）

## 检查清单

### P1 对策的针对性（抗"套模板"测试）

- [ ] **互换测试**：把对策章中所有与本文主题相关的专门术语（如"互联网保险""河南省""农村基层""认罪认罚"）替换为其他领域词，文本是否仍然通顺？若仍通顺，对策缺乏针对性。
- [ ] 对策是否仅仅重复了"明确""优化""完善""加强""统一""加大""健全"等通用动词？
- [ ] 对策是否源自本文前章识别的具体困境，而非通行的"套路模板"？

### P2 可操作性

- [ ] 每条对策是否给出了：**谁来做？做什么？怎么做？做到什么程度？**
- [ ] 是否仅停留在"应当 X"这一层，而没写"具体如何 X"？
- [ ] 对新制度的设计是否包含：制度目的、适用范围、启动条件、运行程序、监督机制、救济途径？
- [ ] 是否考虑了实施中的现实障碍（地方保护、部门协调、成本、数据安全、平衡公私利益）？

### P3 "学术包工头"测试（自己不研究、给别人派活儿）

- [ ] 对策章是否充斥"X 省应……""国家应……""立法机关应……""XX 部门应当……"这类祈使句？
- [ ] 作者是否在对策中明确说"本文建议……，具体内容为……"（研究），还是在说"希望 XX 做……"（派活儿）？
- [ ] 对策的句子主语是否几乎都是**非本文作者能决定**的主体？（如果是，命中 Z-P-2）
- [ ] 是否出现"可以学习 X 省在 XX 方面的立法实践""可以借鉴 Y 省在 XX 方面的创新做法"这种把任务推给他人的表述？

### P4 对策与问题的一一对应

- [ ] 前章识别的每一项困境（问题），是否都在对策章有对应的应对？
- [ ] 对策章提出的每一条建议，是否都指向前章某一项具体问题？
- [ ] 是否存在"问题在甲，对策在乙"的张冠李戴？
- [ ] 对策章是否"头疼医头、脚疼医脚"，未触及问题的系统性根源？

### P5 合理性与可行性论证

- [ ] 激进的对策（如"制定 XX 专门法""构建 XX 独立权利""建立 XX 独立机构"）是否做了充分的必要性论证？
- [ ] 主张"专门立法"时，是否说明了为什么现有法律不足以应对？
- [ ] 主张"上升为法律"时，是否说明了为什么要从部门规章/司法解释层级提升至法律层级？
- [ ] 对策是否与现行法律体系冲突？作者是否识别并回应了冲突？
- [ ] **动词是否用对了**？——主张"建立 X 机制"前先确认："我国目前是否已经有 X 机制？"若已有，应当主张"完善""优化"而非"建立"（张老师典型批评：r20 "目前司法实践中并不缺乏多元化纠纷解决机制，因而需要做的是完善而不是'建立'"）
- [ ] 对策动词与对象是否搭配得当？——如作为一项"原则"是否能"治理"？（r22 张老师曾指出"推定治理"的动宾搭配不当）

### P6 结论的升华度

- [ ] 结语是否仅重复了引言和正文的内容？
- [ ] 结语中提到的"未来研究"是否其实就是本文标题涵盖的题中应有之义？
- [ ] 结语是否对本文的创新、局限、后续研究方向有清晰总结？

### P7 对策章的层次感

- [ ] 对策章是否按照"立法—司法—执法—社会"或"宏观—中观—微观"等维度分层？
- [ ] 每层对策是否有不同的着力点，而非同一事物的不同表述？
- [ ] 对策章的小节是否存在内容重叠（如"提高透明度"与"加强监管"的内容交叉）？

### P8 对策中的"配套机制"陷阱

- [ ] "完善相关配套机制与措施"这种标题下，是否实际写的是配套机制？（张老师点过这是典型的文不对题）
- [ ] 所谓的"配套"是否仅是另一项立法建议，而非制度衔接？

### P9 质询问题的准备

- [ ] 如果本文进入答辩，答辩委员可能提出哪些质询？对策章是否能回应？
- [ ] 对关键主张是否能用"一句话"说清？

## 常用批评话术

- "对策空泛。"
- "内容过于原则化、通用化。例如'深化农村土地制度改革''推动地方立法或政策指导意见''强化法官与调解人员培训'等建议，即使非 XX 地区 XX 纠纷，也同样适用。"
- "作者继续给别人派任务——'修订和完善……''在优化……时，我们既要……又要……'。"
- "这种'学术包工头'的做法，其实是回避了本应由自己完成的任务，没做该做的研究。"
- "试问：这些任务，该让一个硕士研究生来做研究，还是该让这个硕士研究生来下命令？"
- "'头疼医头脚疼医脚'，治标不治本。"
- "对策部分一一对应困境部分，停留在表层，未触及系统性、结构性问题。"
- "'构建系统化、统一性的……法律制度'的主张甚至缺乏合理性和可行性。"
- "如何克服地方保护主义、协调不同部门利益、确保数据共享安全等现实障碍，论述不够充分。"
- "便如同'套模板'，本质上属于重复性研究。"

## 写作实操建议

- **对策设计五要素**：目的 × 主体 × 对象 × 程序 × 监督/救济——每条对策至少覆盖三要素
- **对策反射测试**：针对每条对策自问"这条对策如果通过了，如何评估实施效果？"
- **可行性三问**：成本合理吗？执行主体有动力吗？与现行制度冲突吗？
- **一句话总结法**：每条对策用一句 30 字以内的话概括核心主张，如果做不到，说明对策表述还不够清晰
- **结语模板**：本文发现 → 本文主张 → 本文局限 → 未竟之问（但注意"未竟之问"不应是本文标题覆盖的）
