# 维度 ① 选题与问题意识（checklist）

> 关联主规则库 `zhangqinglin-patterns.md` 第二章（Z-T-1 至 Z-T-5）

## 检查清单

### T1 选题大小与学位档位匹配度

- [ ] 本科论文是否选了硕士级选题？（如以"违约责任""侵权责任""基本权利"为题）
- [ ] 硕士论文是否选了博士级综合题？（如"生成式 AI 作品著作权的司法保护"一题涵盖实体+程序）
- [ ] 能否用一句话说清本文要解决的"真问题"？若三句话都说不清，很可能选题过大。
- [ ] 同主题硕博论文已有多少篇？如果已 ≥ 50 篇，作者是否说明了自己的**差异化贡献**？

### T2 研究问题是否真实存在

- [ ] 作者是否把"立法没有专门规定"本身当成"问题"？这通常是研究任务认知错误。
- [ ] 是否把"司法裁判不统一"当成纯粹的立法问题？（很多时候是法律解释问题）
- [ ] 所谓"问题"是否只是作者个人猜想而非司法实践 / 学界争论的焦点？

### T3 标题与实际研究对象是否一致

- [ ] 《X 研究》与《论 X — 以 Y 为视角》这两类题目是否混淆？
- [ ] 摘要中出现的关键词是否与标题一致？（如标题"共同饮酒人"vs 摘要"醉酒驾驶人"）
- [ ] 在目录扫读时，核心研究对象是否贯穿到对策章？

### T4 创新点的表述质量

- [ ] "本文的创新点"段落是**对自己的学术贡献的精准归纳**，还是**空泛的口号**（如"本文创新地研究了……"）？
- [ ] 创新点是否与既有研究形成有效对话？（即能说清"A 学者主张 X，B 学者主张 Y，本文在此基础上主张 Z"）
- [ ] 创新点有无与正文章节对应？

### T5 地域 / 视角的特定性

- [ ] "以 X 省为例"类题目：地方性规范、地方性实践、地方性数据、地方性困境占比是否 > 50%？
- [ ] 如果把"X 省"替换为"Y 省"，正文绝大多数内容是否仍然成立？若是，则命中 Z-T-5（"含豫量太低"型）。

### T6 选题与作者身份的适配性

- [ ] 作者自述的职业背景（如监察机关工作人员）是否被利用？——张老师对"来自实践的作者却没用上实践优势"的批评非常典型。
- [ ] 作者具备完成此题所需的知识储备吗？（如中医医疗过错研究需要医学知识、数据合规研究需要技术知识）

## 常用批评话术（复用自 phrase-bank）

- "选题过大，现有框架和内容无法支撑起《XXX》这么大的题目。"
- "《X》与《论 X — 以 Y 为视角》是两个相关但有区别的题目，而这篇论文实际上写成了后者。"
- "重复他人既有研究结论的内容较多，独立创新的难度较大。如果聚焦在某一个角度（例如'XX'），显然会更实、更深、更有学术价值。"
- "如果不解决（研究对象）这个问题，那么就会出现很多'套模板'式重复研究。"
- "论文现有内容仅仅做了框架式的介绍，并未步入课题的深水区，要么未完成论题的研究任务，要么选题过大。"

## 典型案例（31 份评阅书中）

- 本科《违约责任研究》《违约责任原则研究》《共同饮酒人对同饮者侵权责任问题研究》—— 选题过大、本科阶段难驾驭
- 硕士《生成式 AI 作品著作权的司法保护问题研究》—— 横跨实体法+程序法，三章各可单独成篇
- 硕士《河南省基层社会治理法治化问题研究》—— 含豫量太低
- 硕士《论互联网保险消费者个人信息的法律保护》—— 写成了"消费者个人信息法律保护—以互联网保险为视角"
- 硕士《论〈监察法〉认罪认罚从宽处罚制度的完善》—— 题目过大、同主题已 80 余篇
- 硕士《认罪认罚从宽制度中被害人权利保障研究》—— 应聚焦"被害人量刑建议权"等某一侧面
