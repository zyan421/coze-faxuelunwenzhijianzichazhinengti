# 批注挂载位置原则（v2.7 新增）

## 1. 背景

v2.6 实测中暴露的一个系统性失误：**批注挂载在"问题文本最早出现的位置"，但用户最该看到这条批注的位置往往在别处**。

### 失误案例 A：叶汉杰差异问题

- **问题性质**：本文与叶汉杰 2019 年同名论文高度相似，需说明独创性
- **v2.6 挂载位置**：引言文献综述第 10 页"叶汉杰指出..."句旁
- **理想挂载位置**：引言"主要问题与结构"段（第 9 页"本文主张建立统一..."）——这是论文最接近"贡献说明"的段落，也是答辩委员追问独创性的入口
- **错位原因**：Agent 默认挂在了"叶汉杰"这个名字出现的位置，而非"应该回答这个问题的位置"

### 失误案例 B：监察法缺位问题

- **问题性质**：2018 年监察法施行后法官监察权与审判责任制的关系，全文未涉及——全文级缺失
- **v2.6 挂载位置**：第 35 页赵作海案段落（与监察法无逻辑关联）+ 兜底为左上角便签
- **理想挂载位置**：第三章"困境表现"章首段——这章本来就应该讨论制度新变量，缺失监察法这一点正属于"困境章应当包含但缺失"的内容
- **错位原因**：全文级问题没有单一锚文本，Agent 仓促选了一个不相关位置

## 2. 三项核心原则

### 原则一：挂在"读者最该看到这条批注的地方"，而非"问题最早出现的地方"

**判断方法**：自问"这条批注的读者（导师/作者/答辩委员）读到论文什么位置时，最需要看到这条批注？"

- 若是**独创性 / 贡献度问题** → 挂在论文宣称贡献的位置（"本文主张..."/"本文创新点..."/"本文研究价值..."），不挂在被对比的他人文献处
- 若是**理论框架与实证应用脱节** → 挂在理论框架建立处的章尾（提示作者"这个框架要在后文用上"），或挂在实证章首（提示"这章本应用上前述框架"）
- 若是**研究承诺失约**（摘要承诺X但全文未做X）→ 挂在做出承诺的摘要/研究方法段，不挂在缺失的章节处
- 若是**法规版本混淆 / 概念前后不一** → 挂在首次混用处，并在批注中提示"全文统一"
- 若是**笔误 / 引注格式 / 单点错误** → 挂在错误本身的位置（这一类是默认）

### 原则二：全文级问题挂在论文相关章节的章首段

**判断方法**：全文级问题（如某重大变量缺失、某概念体系未建立）没有单一锚文本，但**论文必然有一个章节"本来就该讨论这件事"**——挂在那个章节的章首段。

- 监察法缺位 → 困境章章首段（因为困境章应当扫描制度新变量）
- 案例分析单一 → 研究方法段或案例章章首
- 理论框架未论证 → 理论章章首段
- 研究局限未讨论 → 结论章首段

**禁止**：把全文级问题挂在与之逻辑无关的具体段落（如把"监察法缺位"挂在赵作海案段，仅因为这一段提到了刑事追责）——这会让读者困惑批注与正文的关联。

### 原则三：比较性问题挂在"贡献说明"的位置

**判断方法**：所有"本文 vs 他人""本文相对于 X 文有何推进"的批注，都属于学术贡献评价范畴，必须挂在论文宣称贡献的入口：

- 优先位置：论文中明示作者主张的段落（"本文主张..."、"本文认为..."、"本文的创新..."、"本文的研究价值..."）
- 次选位置：引言"主要问题与结构"段、摘要研究方法段
- **不应挂在**：被对比文献的引用位置、文献综述列举段、参考文献条目

理由：答辩委员翻论文找作者贡献时，看的是宣称贡献的段落；批注挂在那里，读者一眼能看到"哦，这里我说的贡献需要进一步与 X 文区分"。挂在被对比文献处，作者只会觉得"是的我知道有这个学者"，意识不到要回答的问题。

## 3. 挂载位置的决策流程

每条 issue 在写 `anchor_text` 之前，Agent 应当先回答三个问题：

```
Q1: 这条批注的核心是什么？
  → 学术诚信问题 → 挂在违规出现的位置（默认）
  → 形式问题（笔误/格式）→ 挂在错误本身（默认）
  → 实质性问题（论证缺陷/独创性/逻辑/承诺失约）→ 进入 Q2

Q2: 这是不是"全文级"或"跨章节"问题？
  → 是 → 挂在最相关章节的章首段（原则二）
  → 否 → 进入 Q3

Q3: 这是不是比较性 / 贡献评价问题？
  → 是 → 挂在论文贡献说明位置（原则三）
  → 否 → 挂在问题最显著的位置（默认）
```

## 4. anchor_text 选取的相应调整

挂载位置决定后，`anchor_text` 应当选取**该位置上能精确命中且与批注内容呼应**的短句。例如：

- 挂在"贡献说明"段时，anchor 选段落首句的核心短语（"本文主张建立统一的审判责任追究"）
- 挂在章首段时，anchor 选章首第一句的核心短语（"完备的责任规范体系以及科学的责任认定标准"）

## 5. 实例：v2.6 → v2.7 的挂载位置改进

| 问题 | v2.6 挂载位置 | v2.7 挂载位置 | 改进原理 |
|---|---|---|---|
| 叶汉杰差异未说清 | p10 文献综述"叶汉杰" | p9 "本文主张建立统一..." | 原则三：挂贡献说明 |
| 监察法缺位 | p35 赵作海案段（错位）→ 兜底左上角 | p36 困境章首段"完备的责任规范体系" | 原则二：挂相关章节章首 |
| 1979 刑法第188条 | p29 "该法第188条首次"（搜不到失败）→ 左上角 | p29 "徇私枉法、滥用裁判权"（同句更鲁棒的 anchor） | anchor 选取容错（见 `anchor-text-locator.md` § 6） |
| 第30条语法+版本混淆 | p30 "有该法第30条"（搜不到失败）→ 左上角 | p30 "以专章形式确立了法官惩戒制度" | 同上 |

## 6. v2.7 之后的候选改造

- `tools/annotation-placement-check.py`：发布前自审脚本，检查每条 issue 的挂载位置是否符合本规则
- `templates/issues-anchor-guide.md`：为不同类型的 issue 提供"推荐挂载位置"快查表
